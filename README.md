# 汽车租赁系统（Java）

面向对象程序设计课程实验：用**抽象类 + 继承 + 多态**实现一个简易汽车租赁计价程序。

## 类设计

```
MotoVehicle        抽象基类（车牌号、颜色）
├── Car            轿车：按车型定价
│                  宝马 500 元/天，别克 300 元/天
└── Bus            客车：按座位数分档
                   12 座 800 元/天，30 座 1500 元/天，45 座 1500 元/天

Customer           客户（身份证号、姓名）+ calcTotalRent(vehicle, days)
TestRent           主程序，控制台交互
```

考点：把 `Car` 和 `Bus` 对象统一放进 `MotoVehicle[]` 数组，通过多态调用各自的计价逻辑。

## 功能

1. 预置 6 台可租赁车辆（3 辆轿车 + 3 辆客车）
2. 输入客户身份证号与姓名
3. 列出全部车辆的车型/座位数、颜色、日租金
4. 选择车辆序号与租赁天数，输出总租金

## 编译运行

```bash
cd src
javac -encoding UTF-8 -d ../out TestRent.java geo/motos/*.java geo/users/Customer.java
java -cp ../out TestRent
```

也可以用任意 IDE 打开 `src` 目录，直接运行 `TestRent`。

## 已知问题

`TestRent.java` 里打印表头那一行用的是 `System.err.println`（应为 `System.out`），所以表头会跑到标准错误流里。功能不受影响，但做输出重定向时表头会丢。

## 环境
